FitForge – Fitness Tracking Application

FitForge is a fitness tracking application built using React and Firebase. It helps users manage their fitness journey by tracking workouts and nutrition through a simple and user-friendly interface.

Features

- User Login and Authentication
- Personalized Dashboard
- Workout Logging and Tracking
- Nutrition Tracking
- Responsive User Interface

Technologies Used

- React.js
- JavaScript
- Firebase
- HTML5
- CSS3

Installation and Setup

1. Clone the repository:
   
   "git clone https://github.com/chitrasuraju-r/FitForge-App"

2. Navigate to the project folder:
   
   "cd FitForge-App"

3. Install dependencies:
   
   "npm install"

4. Start the development server:
   
   "npm run dev"
